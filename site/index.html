Install Narcissu

Add to your device

Install Narcissu for a standalone, landscape-first reading experience.

Android / Chrome: choose Install app from the browser menu, or use the install prompt when it appears.

iPhone / iPad: open the Share menu in Safari, choose Add to Home Screen, then launch Narcissu from the Home Screen.

On iOS, the browser may not enforce landscape orientation. If it opens in portrait, rotate your device to continue.
